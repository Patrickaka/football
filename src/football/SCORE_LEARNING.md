# 比分 Top3 学习链修复（2026-09-08）

沿用现有 Poisson / 负二项、Dixon-Coles、市场锚定、校准和 TopK 评价。
主页面、胜平负百分比、让球推荐规则保持原样，没有用 LLM 生成比分概率。

## 修复内容

- 静态盘口历史融合原先传入 `model/market` 权重，底层却读取 `poisson/market`，
  异常被捕获后静默跳过。现在由 `scoring.apply_static_score_prior` 执行凸组合，
  实际概率写回完整矩阵，并记录真正使用的权重与样本数。
- 原增量学习对已归一化的概率直接 `+1`，导致一场赛果获得接近一半权重。
  现在按真实次数更新。例如 100 场的 50/30/20 次，新增第一个比分后为
  51/101、30/101、20/101，而不是对 0.5 直接加 1。
- 无法用概率和 N 核验次数的旧桶保留原字段，通过独立 `fresh_counts`
  累计修复后的真实新赛果。保存、重载、查询不伪造丢失的旧计数。
  `MarketScoreDB.count()` 只统计可用的真实样本。
- 近邻盘口的概率与 N 来自同一个桶。CSV `>2.5/<2.5` 报价按实际 2.5 球
  盘口入桶，不再把赔率隐含的总进球均值当成盘口。
- 移除集成成员内已损坏的重复盘口变化融合，继续使用 pipeline 的单次变化先验。
- 修正 DC 辅助结果 NumPy 主客胜求和方向，未调整 DC 公式和 rho 参数。
- 历史 8-0 等比分超出基础网格时，以零补齐矩形支持域，保留真实尾部质量。
  页面和冻结评价使用同样的概率排序及同概率比分顺序。

## 使用边界

保留既有策略上限，默认 15%，按 `min(N/300, 1)` 和市场质量缩小。
少于 30 个有效样本、盘口距离大于 0.5、比分支持不足或非法概率时退回基础模型。
代理、未匹配、不可用的盘口不能触发历史融合。三个显示比分不重新归一化，
也不为覆盖不同方向强行替换更高概率比分。

`model.static_market_prior` 记录桶、有效 N、实际权重和原因。
集成权重仅描述后续市场锚定及校准之前的阶段，不能当成整个系统的贡献率。
旧聚合的损坏及旧 CSV 建库造成的盘口歧义，无法只靠聚合值完全恢复。
本次没有覆写生产数据库或把旧导出伪装成赛前冻结样本。

## 可重复验证

```powershell
.venv/Scripts/python.exe scripts/diagnose/replay_football_score_learning.py --output reports/football_score_learning_replay.json
.venv/Scripts/python.exe -m pytest -q -p no:cacheprovider --tb=short
```

重放复用生产融合函数和 `score_metrics`，报告 Top1/3/5/10、真实比分排名、
比分 Brier / LogLoss、按日期配对区间、分联赛和前后时段结果。
每天先生成全部预测，再将当天赛果加入内存历史；参数固定，不搜索有利权重。
只读本地 CSV、写指定报告，不读写业务数据库或运行模型。

这是独立学习环节的按日期消融验证，覆盖五联赛 2.5 球报价，缺少原始采集时刻
及当时的球队、首发、伤停快照。它不是完整生产重跑或未使用的新赛季验收，
`release_qualified` 为 false。线上是否提升仍以新版本真实冻结事件的赛后评价为准。

逻辑版本 `2026-09-08-score-learning-v45`，生产记录版本
`football-v2026.09.08-score-learning-19`；旧缓存失效，新旧效果按版本区分。

## 本地回放结果

本地十份 CSV 去重和剔除缺字段后为 3,499 场。第一赛季 1,752 场积累历史，
第二赛季 1,747 场、178 个比赛日，其中 1,722 场达到历史先验使用条件。

| 第二赛季指标 | 相同基础矩阵 | 加入比分历史 |
| --- | ---: | ---: |
| Top1 | 12.879% | 13.165% |
| Top3 | 34.917% | 34.974% |
| Top5 | 49.857% | 50.487% |
| Top10 | 77.905% | 78.191% |
| 比分 LogLoss | 2.887066 | 2.886423 |
| 比分 Brier | 0.926664 | 0.926454 |

Top1 多命中 5 场、Top3 多命中 1 场，幅度很小。LogLoss 改善的按日期配对
95% 区间为 [-0.001387, 0.002789]，跨过零，Brier 区间也跨零。
全部 3,499 场的 Top3 从 34.438% 变为 34.410%（少 1 场）；第二赛季前半段
Top3 及 LogLoss 变差、后半段变好，分联赛也不一致。
因此本次修复恢复了学习链的正确运行，但尚未证明稳定的比分准确率提升。
没有据这些结果后验选择有利的联赛、权重或比赛，也没有将报告用作自动发布准入。
